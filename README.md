### 📊 Featured project — [AdventureWorks Sales Performance Dashboard](https://github.com/emmanuelcecilia-data/adventureworks-sales-dashboard)

[![AdventureWorks sales dashboard](https://raw.githubusercontent.com/emmanuelcecilia-data/adventureworks-sales-dashboard/main/images/overview.png)](https://github.com/emmanuelcecilia-data/adventureworks-sales-dashboard)

An executive Power BI dashboard that **explains itself**: a Key Insights panel writes plain-English findings with DAX and rewrites them as you change the year or metric.

- Star-schema model with a fiscal-year date table and 75 DAX measures
- One-click switch between Sales, Profit and Orders across every chart
- Designed first (mockup, pixel grid, custom theme), then built and verified against the source data
